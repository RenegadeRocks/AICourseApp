# Week 4 lesson briefs — Building a sales agent & comprehensive RAG AI agent

Week identity: Sessions "Building a Sales Agent" (2026-06-13) + "Building Comprehensive RAG AI Agent" (2026-06-14). Study window 2026-06-08 to 2026-06-14.

Week thesis: The two most-deployed AI-worker categories in 2026 are the outbound/inbound sales agent and the knowledge-grounded RAG agent. Both are commoditized at the "hello world" level (11x, Artisan, Regie for sales; any LangChain tutorial for RAG) and are ruthless at production scale. This week is the mechanistic depth that separates a sales agent that generates real pipeline from one that gets your domain blacklisted, and a RAG agent that answers 85% of enterprise queries from one that hallucinates on 40% of them. Week 4 covers: (1) what a sales agent actually does end-to-end and the vendor teardown, (2) the agent architecture stack applied (Anthropic Building Effective Agents, tool-calling loops, MCP), (3) outbound deliverability + compliance — the "ignore this and you ship to 0% inbox" layer, (4) RAG fundamentals with the 2024/25 frontier (contextual retrieval, hybrid search, reranking), (5) advanced RAG (GraphRAG, agentic retrieval, long-context vs RAG), (6) RAG evaluation with real harnesses.

**Block 0 / Block 1 overlap to AVOID:**
- Block 0 Weeks 0–2 covered LLM fundamentals + prompting + Claude Code; reference, don't re-teach.
- Block 1 Week 1 Wed covered discovery/qualification from a sales conversation angle — this week is the AUTOMATED BUILD, not the human conversation.
- Don't re-teach tool use or MCP from first principles — reference Anthropic docs and dive into agent patterns.
