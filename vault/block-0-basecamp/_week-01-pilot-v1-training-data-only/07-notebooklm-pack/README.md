# NotebookLM Pack — Week 01: Prompting, RAG & Vibe Coding

## How to use this pack

1. Open [NotebookLM](https://notebooklm.google.com) (requires a Google account).
2. Create a new notebook. Name it "AI Catalyst C3 — Week 01".
3. Click **Add sources** → **Upload file**.
4. Upload `bundle.md` from this folder.
5. Wait for indexing (30–60 seconds).
6. You can now ask questions like:
   - "What is contextual retrieval and why does it matter?"
   - "Compare Cursor and Claude Code for vibe coding"
   - "Summarize the common mistakes in RAG pipelines"
   - "Give me a study guide for the Saturday live session"
   - "Quiz me on prompting mechanics"
